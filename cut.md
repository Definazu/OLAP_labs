# Границы проекта

| Вне проекта | Последствие для отчёта или эксплуатации |
|---|---|
| История магазинов, названий и брендов товара | Обновление региона магазина в источнике перенесёт его старые продажи в новый регион. Например, после смены региона магазина 1 переедут 49,00 ден. ед. оборота квартала. Категории товара версионируются отдельно. |
| Возвраты, скидки и состав чека | По выгрузке доступны суммы позиций. Чистый оборот с учётом возвратов, скидку и средний чек по ней вычислить нельзя. |
| Потоковая загрузка и инкрементальный пересчёт | Отчёт обновляется после полного ELT. Публикация таблиц ClickHouse идёт по очереди. Рабочий полный пересчёт запускают между сеансами просмотра отчёта, чтобы не читать разные снимки в одном запросе. |
| Кластер ClickHouse | При остановке локального контейнера дашборд временно недоступен. |
| Модель прогнозирования | Витрина описывает наблюдавшиеся продажи. Для прогноза нужны более длинная история и отдельная проверка модели. |
